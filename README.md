# MyBuyo Biometric SaaS
### by Cygel White | FacePrintPay | Kre8tive Koncepts

> "Your face is your wallet. Your fingerprint is your password."

## Overview
MyBuyo Biometric SaaS is a sovereign, on-device biometric authentication
platform. No passwords. No PINs. No third-party auth providers.
Pure biometric identity — face, fingerprint, device-bound.

## Packages
- `@mybuyo/core` — biometric engine
- `@mybuyo/auth` — authentication middleware  
- `@mybuyo/pay` — payment verification
- `@mybuyo/sdk` — client SDK
- `@mybuyo/gate` — API gateway

## Stack
- Termux:API (fingerprint/face)
- Node.js + Express
- SQLite (on-device)
- Constellation25 agents
- FacePrintPay blockchain
